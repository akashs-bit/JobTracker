## 📌 About The Project

JobTracker is a full-stack job application tracking platform designed to simplify
the job search and recruitment process.

Candidates can search and filter jobs, view job details, apply with a resume,
save jobs for later, and track their application status.

Administrators can manage job listings, review applications, manage applicants,
and update application statuses through a dedicated dashboard.
