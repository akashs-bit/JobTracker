## 📌 Overview

**JobTracker** bridges the gap between job seekers and recruiters. Candidates can discover positions, upload resumes, save listings, and follow their application progression in real time. Meanwhile, administrators manage listings, evaluate candidates, and schedule interviews via a centralized dashboard.

---

## ✨ Features

| Candidate Features | Admin Features |
| :--- | :--- |
| **Authentication:** Secure Register & Login | **Dashboard:** Platform metrics & overview stats |
| **Discovery:** Search & advanced job filters | **Listing Management:** Create, edit, & remove jobs |
| **Applications:** Apply with direct resume upload | **Candidate Review:** Evaluate applications & resumes |
| **Saved Jobs:** Bookmark opportunities for later | **Status Updates:** Real-time application updates |
| **Tracking:** Live status tracking & scheduling | **Interview Portal:** Schedule & manage interviews |
